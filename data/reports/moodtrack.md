# MoodTrack｜個人情緒與壓力紀錄分析平台

程式設計 Python 課程期末專案。每天花 30 秒記下心情、壓力、睡眠與運動，系統用統計與圖表幫你看見自己的生活模式。

## 主要功能

- 使用者註冊、登入、登出，密碼以雜湊儲存
- 每日情緒紀錄的完整 CRUD（新增、查看、編輯、刪除），每人每天一筆
- 歷史紀錄：日期／分數篩選、分頁
- **儀表板**：心情日曆（最近 5 週，顏色深淺代表心情）、連續記錄天數、最近 7／30／90 天統計卡片、心情與壓力趨勢圖、睡眠趨勢圖、運動長條圖
- **資料分析**：不同期間平均、最高最低紀錄、運動與壓力比較、睡眠與心情散佈圖
- 響應式介面（手機可用）、自訂錯誤頁面

## 使用技術

| 類別 | 技術 |
|---|---|
| 後端 | Python 3、Flask 3 |
| 資料庫 | SQLite、Flask-SQLAlchemy（ORM） |
| 使用者認證 | Flask-Login、Werkzeug 密碼雜湊（scrypt）、Flask-WTF（CSRF 保護） |
| 前端 | Jinja2 模板、HTML、CSS（含手機版排版） |
| 資料視覺化 | Chart.js |
| 測試 | Python `unittest`，共 35 項自動化測試 + 33 項瀏覽器端到端測試 |

## 安全設計

| 項目 | 做法 |
|---|---|
| 密碼 | 只存雜湊，資料庫裡沒有明文密碼 |
| 登入權限 | 儀表板、紀錄、分析頁都加上 `@login_required` |
| 資料隔離 | 所有查詢都加上 `user_id`；改網址存取別人的紀錄會得到 404 |
| 刪除 | 只接受 POST，並在刪除前跳出確認；不能用開網址的方式刪除 |
| CSRF | Flask-WTF `CSRFProtect`，所有表單都帶 token |
| Cookie | `HttpOnly`、`SameSite=Lax`，HTTPS 下加上 `Secure` |

> 共 68 項自動化與端到端測試，已部署上線運行。
