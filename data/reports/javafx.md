# JavaFX 蛋糕疊疊樂

計算機實習期末專題。使用 JavaFX 製作的桌面迷你遊戲。

## 遊戲玩法

- 點擊畫面讓蛋糕掉落。
- 蛋糕沒疊準就會被切掉，只保留對齊的部分。
- 可以選擇難度，疊得越高分數越高。

## 程式架構（MVC）

| 資料夾 / 檔案 | 內容 |
|---|---|
| `Main.java` | 主程式進入點 |
| `Controller/` | 控制邏輯：處理點擊、掉落、切片判定、計分 |
| `View/` | UI 與畫面顯示 |
| `Model/` | 蛋糕與切片的資料結構 |
| `Assets/` | 圖片資源（蛋糕、標題圖等） |

## 技術重點

- 以 **JavaFX** 建構畫面與動畫，Java 物件導向設計。
- 採 **MVC 架構**將畫面、邏輯與資料分離，方便維護與分工。
- 團隊協作以 Git 分支開發，確認無誤再合併。
