# 識詐群島｜用遊戲學防詐騙

Microsoft AI 競賽作品。在島上走動、打開寶箱，判斷裡面的簡訊／Email／聊天／網頁／來電是不是詐騙。答對賺金幣，買裝備、解鎖新島嶼。

## 遊戲內容

- **五座島嶼**：新手島、職場島、購物島、投資島、校園島，每座島有不同情境的寶箱題目。
- **題目類型**：簡訊、電子郵件、聊天、來電、網頁、手機通知，玩家要判斷真假並找出破綻。
- **金幣與錯題本**：第一次作答才有金幣；答錯會進錯題本，訂正可補分；金幣能買裝備、解鎖內容。
- **阿嬤家任務**：扮演幫長輩判斷詐騙的角色，依選擇影響「阿嬤安心度」。
- **每日挑戰、建築小遊戲**：職缺看板、網址真假考驗、訊息快篩、投資廣告找碴等。

## AI 功能

| 功能 | 說明 |
|---|---|
| 💬 AI 防詐助手 | 隨時問防詐問題，先查知識庫再回答並標註來源 |
| 🔍 可疑訊息檢查 | 貼上可疑訊息，AI 給風險指數、破綻與建議 |
| 🎭 詐騙者對練 | AI 扮演詐騙者聊天，結束後 AI 教練覆盤 |
| 📅 AI 每日出題 | AI 依知識庫出是非題，玩家可回報有問題的題目 |

## 技術架構（輕量版 RAG）

```
瀏覽器 → /api/ai（Netlify Function）
  → BM25 關鍵字 + 中文雙字詞，從知識庫（109 筆）找出最相關 5 筆
  → 連同問題送給模型 → 回傳答案與來源
```

- **前端**：HTML / CSS / 原生 JavaScript，進度存在瀏覽器 localStorage。
- **後端**：Netlify Functions；AI 模型使用 **Microsoft Foundry（Azure for Students）**，API 金鑰只放在伺服器端。
- 後端連不上時自動退回內建題庫，遊戲照常可玩。
