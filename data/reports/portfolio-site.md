# 個人作品集網站｜Cyberpunk 霓虹風格全端網站

使用 Node.js + Express + EJS + SQLite 從零打造的個人作品集網站，具備會員系統、文章與作品管理、後台與留言審核，並採 cyberpunk 霓虹視覺風格，部署於 Render。

## 使用技術

| 類別 | 技術 |
|---|---|
| 後端 | Node.js、Express |
| 樣板引擎 | EJS |
| 資料庫 | SQLite（better-sqlite3） |
| 會員認證 | express-session、bcryptjs 密碼雜湊 |
| 前端 | HTML、CSS、原生 JavaScript |
| 部署 | Render（綁 GitHub 自動部署） |

## 主要功能

- **會員系統**：註冊、登入、登出，密碼以 bcrypt 雜湊儲存，區分一般使用者與管理員。
- **後台管理**：管理員可新增、編輯、刪除作品集與文章。
- **作品集**：分類篩選、關鍵字搜尋，每個作品有專屬詳細頁。
- **文章 / 部落格**：文章列表、分頁、搜尋，文章內頁含留言板。
- **留言審核**：會員或訪客皆可留言，須經管理員審核後才公開顯示。
- **聯絡表單**、自訂 404 頁面、手機版響應式選單。

## 視覺設計重點（Cyberpunk）

- **賽博城市背景**：以夜景城市圖為底，加上亮度壓暗、暗化遮罩與掃描線，確保文字清楚。
- **故障（glitch）特效**：標題與品牌文字以青／洋紅雙色錯位疊色，平常固定、每隔幾秒短暫故障爆發一次。
- **霓虹 UI**：按鈕、頁碼、後台分頁統一為透明霓虹外框，滑過時亮暗交替閃爍並發光；卡片為玻璃質感＋四角霓虹角標。
- **科技感字體**：標題使用 Orbitron，整體以 Rajdhani 強化未來感。
- **故障游標**：自製跟隨滑鼠的青／洋紅抖動方框游標（移到嵌入視窗時自動隱藏）。

## 作品展示機制

- **即時網頁預覽**：有 Demo 連結的作品，卡片自動顯示該網頁的即時截圖縮圖。
- **互動嵌入視窗**：可直接在頁面內操作的 Demo（如識詐群島、NCU Research Gateway、MoodTrack），左側嵌入、右側介紹。
- **作品詳細頁**：每個作品都有專屬頁面，整合嵌入 Demo／截圖／說明，並以 Markdown 動態渲染各專案的成果報告。
- **Spotify 嵌入**：首頁底部嵌入推薦音樂歌單。

## 安全與工程細節

- 密碼僅存 bcrypt 雜湊，資料庫無明文密碼。
- 留言預設待審核，避免未經把關的內容公開。
- 以 `engines` 鎖定 Node 版本，確保部署平台使用有預編譯檔的版本，避免原生套件編譯失敗。
- CSS 以版本參數（cache busting）避免瀏覽器讀到舊樣式。
