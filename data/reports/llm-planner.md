# LLM-Planner｜具身代理的少樣本任務規劃

畢業專題。探討如何以**大型語言模型（LLM）**為具身代理（embodied agent）做少樣本（few-shot）的任務規劃：代理在模擬環境中接到一句自然語言指令（例如「把馬克杯放到咖啡機上」），由 LLM 生成一連串高階步驟，再交給低階控制器執行。

## 核心概念

- **Grounded planning**：LLM 產生的計畫會依據環境中「實際觀察到的物件」動態調整，而不是只憑文字空想，降低計畫無法執行的情況。
- **Few-shot 檢索式提示**：用 kNN 從少量示範中挑出最相似的例子組成提示，讓 LLM 不需大量訓練就能規劃。
- **高階 / 低階分工**：LLM 負責高階計畫，低階控制器負責實際動作，兩者分離。
